# StockGuard UI Visual Assets & Screenshots

This directory holds visual assets and interface mockups embedded in [`README.md`](../../README.md).

### Bundled Visual Mockups (Vector SVG):
1. **`catalog-screen.svg`**: Real-time product catalog with multi-field search, category chips, hardware silicon circuit die fallbacks, and live stock badges (In Stock, Low Stock, Out of Stock).
2. **`cart-modal.svg`**: Shopping cart modal with line item quantity steppers, duplicate order protection banner, and estimate summary.
3. **`orders-modal.svg`**: Customer order history modal showing order status pills, delivery notes, and immutable historical unit price snapshots.
4. **`inventory-ledger.svg`**: Administrator control console showing 5 high-level KPI cards and the append-only immutable audit movement ledger table.

### Live PNG Capture Replacement:
If you capture live application screenshots from a running local instance (`http://localhost:5173`) at 1440px desktop viewport, save them alongside or in place of the `.svg` files:
- `catalog-screen.png`
